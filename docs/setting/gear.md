# 器具与局外解锁

试玩关固定使用家传短刃，数值就是脚本里的三连伤害。下面几件都还没做进关卡，只定名字和以后的用途。

## 武器

| 名字 | 谁有关 | 以后的差别 |
| --- | --- | --- |
| 家传短刃 | 林狩开局 | 现在就能用。三连：8 / 11 / 16。投技那一下是 14 |
| 崔氏猎刀 | 崔锻 | 攻击比短刃高一截，连段节奏不变 |
| 棘木棒 | 猎场边上可以捡的重器械 | 更慢，单下更重。试玩不掉落 |
| 浸叶刃 | 茴娘 | 命中后追加一小段伤害。试玩没有 |

## 三件局外解锁

打完以后才会用猎场上带回去的东西换。第一关没有商店，也没有存档。

| 解锁 | 作用 |
| --- | --- |
| 淬骨 | 开局最大生命提高 |
| 开刃 | 开局攻击提高 |
| 识途 | 命中后的接招窗口略长 |

三件互相不替代武器，只改猎人自己的底子。
