# 战斗（第一关就这些）

地面攻击是三连。没有全屏慢动作：命中只让出手的人和被打中的那一只短暂停住，其余的人和画面时间照常走。没有坐骑。

## 接招

1. 平常按 J，一定是第一击。
2. 第一击打中之后，才允许第二击。第二击打中之后，才允许第三击。
3. 打中之后要再按一次 J。窗口是：这一击的攻击判定结束后可以立刻接，若当时没按，收招结束起再留 0.28 秒。
4. 判定还没打中就提前按 J，不算接招。
5. 打空：这一下不点亮下一击。下一次按 J 回到第一击。
6. 第三击打完，连段结束。再按 J 又是第一击。
7. 猎人被扑中时，当前连段断开，下一击从第一击算。

每一击都会把挥击播完（或在判定结束后被合法的下一击取消后摇）。不会在挥空的半途自动变成下一击。

## 第三击

第三击起手的那一帧看方向键，不看命中那一帧，也不看 W / S。

| 起手时按住 | 结果 |
| --- | --- |
| ↑ | 向猎人背后投 |
| ↓ | 向猎人面朝的方向投 |
| ↑ 和 ↓ 一起 | 向背后投（上优先） |
| 都没按 | 击倒 |

投出去或打倒的野兽会倒地一小段时间，这段时间打不中。倒地爬起来后还有很短的不可打中，避免无限连。

## 顿帧

只停攻击者和这一下打中的目标。

| 情况 | 大约时长 |
| --- | --- |
| 第一击、第二击 | 85 毫秒 |
| 第三击击倒 | 150 毫秒 |
| 第三击投技 | 130 毫秒 |

实现上不改全局 `Engine.time_scale`。

## 移动

左右是猎场方向。上下是同一条地面上的纵深，不是跳。W 是跳。跳在空中时，地面三连出不来；野兽贴地的扑咬也打不中人。

## 试玩数值

- 林狩生命 100。刺脊兽扑中一次 10。
- 刺脊兽生命 35。三连伤害 8、11、16，打满可以放倒一只。投技那一下是 14，所以「投」完通常还要再补一击。
- 场上三只刺脊兽。
