# 地方

地名都是本作原创。试玩只开放荆丛猎场。没有坐骑，路都是人走的。

## 荆丛猎场

林子边缘的猎场，第一关「猎归」的全部场景。地面不平，人可以左右走，也可以在一条纵深带里靠近或远离画面。这里只有野兽（刺脊兽），没有村落、没有葛叶部。

清完野兽，关卡文字会说明猎户村还在前头。试玩不加载下一张地图。

## 猎户村

林狩、林穗、崔锻、茴娘、桂婶住的村子。故事开始时已经被葛叶部闯过一次，所以林狩从猎场往回赶。村子不是第一关的内容。

## 星火夜营

猎场和村子之间的过夜点。以后如果做赶路，人会在这里停，不是骑马的驿站。当前没有这张关。

## 百草坡

猎户村后头的药坡，茴娘采药的地方。当前没有这张关。

## 西荒野

村子西边更干的野地，葛叶部出发的那一侧。他们被称为青肤掠夺者：皮肤发绿，是长期用荆汁涂面，又住在毒叶林边上，不是从别的作品借来的种族名。本关遇不到他们。
